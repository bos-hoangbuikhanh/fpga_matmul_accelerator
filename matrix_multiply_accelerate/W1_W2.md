# PHÂN CÔNG CÔNG VIỆC — RISC-V Matrix Accelerator

**Dự án:** Thiết kế bộ nhân ma trận 8×8 INT16 tích hợp RISC-V trên FPGA Cyclone IV EP4CE6

**Thời gian:** 26/10/2026 – 08/11/2026 (2 tuần)

**Thành viên:** Huy, Cảnh, Hoàng, Lê

## 1. Mục tiêu

Hoàn thành hai giai đoạn đầu của đề tài:

- **Giai đoạn 1:** Thiết kế Matrix Multiplication Accelerator 8×8 signed INT16 sử dụng PE/MAC Array.
- **Giai đoạn 2:** Tích hợp accelerator với RISC-V PicoRV32 trên Cyclone IV EP4CE6.

**Kết quả cuối cùng:** RISC-V chạy chương trình C để điều khiển accelerator thực hiện phép nhân hai ma trận 8×8, đọc kết quả và hiển thị PASS/FAIL qua UART.

## 5. Interface và thông số chung

| Thông số | Cấu hình |
|---|---|
| FPGA | Cyclone IV EP4CE6 |
| RISC-V | PicoRV32 RV32I |
| Clock mục tiêu | 50 MHz |
| Matrix | 8×8 |
| Input | Signed INT16 |
| Accumulator | Signed INT35 |
| PE Array | 2×2 (4 MAC) |
| Bus | PicoRV32 native memory interface |
| Communication | UART |
| Verification | Verilog testbench + Python |

### Memory-Mapped Registers (đề xuất)

| Offset | Register | Chức năng |
|---|---|---|
| 0x00 | CONTROL | START / RESET |
| 0x04 | STATUS | BUSY / DONE |
| 0x08 | MATRIX_A_ADDR | Địa chỉ ma trận A |
| 0x0C | MATRIX_B_ADDR | Địa chỉ ma trận B |
| 0x10 | MATRIX_C_ADDR | Địa chỉ ma trận C |

Memory map cần được Hoàng và Lê thống nhất trước khi triển khai firmware.

## 9. Tiêu chí hoàn thành dự án

Dự án được xem là hoàn thành khi:

1. Nhân chính xác hai ma trận 8×8 signed INT16.
2. Accelerator sử dụng PE/MAC Array và hỗ trợ data reuse.
3. PicoRV32 chạy firmware C trên EP4CE6.
4. RISC-V điều khiển accelerator qua memory-mapped interface.
5. Kết quả được kiểm tra bằng golden model.
6. Có báo cáo DSP, LE, BRAM, Fmax và latency.
7. Có demo thực tế trên FPGA.

**Định hướng tiếp theo:** Sau khi hoàn thành hai giai đoạn, nhóm sẽ mở rộng accelerator sang INT8 Fully Connected Layer để port mô hình TinyML lên EP4CE6.
